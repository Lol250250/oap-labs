## Завдання 1 — розв'язання квадратного рівняння

### Постановка та гілки

Для введених дійсних коефіцієнтів `a`, `b`, `c` розв'язати рівняння:

\[
ax^2 + bx + c = 0.
\]

Перед обчисленнями перевіряється коректність введення та скінченність усіх коефіцієнтів. Далі розглядаються випадки:

1. `a = 0`, `b = 0`, `c = 0` — будь-яке `x` є розв'язком.
2. `a = 0`, `b = 0`, `c != 0` — коренів немає.
3. `a = 0`, `b != 0` — лінійне рівняння, `x = -c/b`.
4. `a != 0`, `D < 0` — дійсних коренів немає.
5. `a != 0`, `D = 0` — один дійсний корінь.
6. `a != 0`, `D > 0` — два дійсні корені.

У програмі порівняння з нулем виконується з допуском `EPS = 1e-9`. Результати виводяться з чотирма знаками після коми.

### Трасування до кодування для `a = 1`, `b = -3`, `c = 2`

| Крок | Перевірка / обчислення | Результат |
|---|---|---|
| 1 | Перевірка введення | Усі три числа коректні |
| 2 | `fabs(a) < EPS` | Ні, `a = 1` |
| 3 | `D = b*b - 4*a*c` | `9 - 8 = 1` |
| 4 | `D < -EPS` | Ні |
| 5 | `fabs(D) < EPS` | Ні |
| 6 | `sqrt(D)` | `1` |
| 7 | `x1 = (-b - sqrt(D))/(2*a)` | `1.0000` |
| 8 | `x2 = (-b + sqrt(D))/(2*a)` | `2.0000` |

Очікуваний результат: два корені `1.0000` і `2.0000`.

### Тести

| Ввід `a b c` | Очікуваний результат | Яку гілку перевіряє |
|---|---|---|
| `1 -3 2` | Два корені: 1.0000 і 2.0000 | `D > 0` |
| `1 2 1` | Один корінь: -1.0000 | `D = 0` |
| `1 0 1` | Дійсних коренів немає | `D < 0` |
| `0 2 -4` | Лінійний корінь: 2.0000 | `a = 0`, `b != 0` |
| `0 0 0` | Будь-яке `x` | `a = 0`, `b = 0`, `c = 0` |
| `0 0 5` | Коренів немає | `a = 0`, `b = 0`, `c != 0` |
| `abc 1 2` | Повідомлення про некоректне введення | Перевірка вводу |

## Завдання 2 — обчислення функції за варіантом 14

### Постановка

Межі: `a = 0`, `b = 3`.

\[
y(x)=
\begin{cases}
|x-1|, & x < 0,\\
x\sin(x), & 0 \le x \le 3,\\
\lg(x), & x > 3.
\end{cases}
\]

У третій гілці `lg(x)` — десятковий логарифм, тобто `std::log10(x)` у C++.

### Псевдокод

1. Прочитати `x`.
2. Якщо введення некоректне або `x` не є скінченним числом — вивести повідомлення про помилку та завершити програму з кодом 1.
3. Якщо `x < 0`, обрати гілку 1 та обчислити `y = |x - 1|`.
4. Інакше, якщо `x <= 3`, обрати гілку 2 та обчислити `y = x * sin(x)`.
5. Інакше обрати гілку 3 та обчислити `y = log10(x)`. Оскільки ця гілка виконується лише для `x > 3`, аргумент логарифма гарантовано додатний.
6. Вивести `x`, номер гілки та `y` з чотирма знаками після коми.

### Трасування — по одному значенню з кожної гілки

| Вхід `x` | Перевірки | Гілка | Обчислення | Результат `y` |
|---:|---|---:|---|---:|
| `-1` | `-1 < 0` — істина | 1 | `|-1 - 1| = 2` | `2.0000` |
| `1.5` | `1.5 < 0` — ні; `1.5 <= 3` — так | 2 | `1.5 * sin(1.5)` | `1.4962` |
| `4.5` | `4.5 < 0` — ні; `4.5 <= 3` — ні | 3 | `log10(4.5)` | `0.6532` |

### Тести, межі та перевірка вводу

| Вхід `x` | Очікуваний результат | Призначення |
|---:|---|---|
| `-1` | Гілка 1, `y = 2.0000` | Контрольний тест гілки 1 |
| `-0.001` | Гілка 1, `y = 1.0010` | Значення ліворуч від `a` |
| `0` | Гілка 2, `y = 0.0000` | Межа `x = a`, належить гілці 2 |
| `1.5` | Гілка 2, `y = 1.4962` | Контрольний тест гілки 2 |
| `3` | Гілка 2, `y = 0.4234` | Межа `x = b`, належить гілці 2 |
| `3.001` | Гілка 3, `y ≈ 0.4773` | Значення праворуч від `b` |
| `4.5` | Гілка 3, `y = 0.6532` | Контрольний тест гілки 3 |
| `abc` | Повідомлення про некоректне введення, код завершення 1 | Перевірка вводу |
| `nan` | Повідомлення про некоректне введення, код завершення 1 | Перевірка скінченності числа |

### Перевірка області визначення та приклад помилки без перевірки

У гілці 3 обчислюється `lg(x)`, для якого область визначення — `x > 0`. За заданими межами ця гілка обирається лише при `x > 3`, тому аргумент логарифма завжди додатний. Наприклад, якби помилково обчислити `lg(-1)` без перевірки області визначення, результатом було б `nan`. У поточній програмі такого обчислення не відбувається завдяки розгалуженню.
