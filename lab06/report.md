## 1. Мета роботи

Навчитися обробляти послідовність цілих температур за допомогою циклу `for`, розгалуження `if / else if / else` та лічильників без використання масиву. Перевіряти кількість елементів, допустимість температур і коректність введення.

## 2. Варіант і межі категорій

Для варіанта 14 задано:

- нижня межа `L = -10 °C`;
- верхня межа `H = 20 °C`.

Категорії:

- `below`: температура `t < -10`;
- `inside`: `-10 ≤ t ≤ 20` (обидві межі включені);
- `above`: температура `t > 20`.

Кількість температур: `1 ≤ n ≤ 30`. Допустимий діапазон кожної температури: `-100 ≤ t ≤ 100 °C`.

## 3. Псевдокод

```text
Початок
    Зчитати n
    Якщо введення помилкове або n не в межах 1..30:
        вивести Error
        завершити з кодом 1

    below = 0
    inside = 0
    above = 0

    Для i від 0 до n - 1:
        зчитати t
        Якщо введення помилкове або t не в межах -100..100:
            вивести Error
            завершити з кодом 1

        Якщо t < L:
            below = below + 1
        Інакше якщо t <= H:
            inside = inside + 1
        Інакше:
            above = above + 1

    вивести below, inside, above
Кінець
```

## 4. Трасування першого тесту

Для варіанта 14: `L = -10`, `H = 20`.

Вхід:

```text
4 -11 -10 20 21
```

| № | Температура t | Перевірка | Категорія | below | inside | above |
|---:|---:|---|---|---:|---:|---:|
| 1 | -11 | `-11 < -10` | below | 1 | 0 | 0 |
| 2 | -10 | `-10 ≤ -10 ≤ 20` | inside | 1 | 1 | 0 |
| 3 | 20 | `-10 ≤ 20 ≤ 20` | inside | 1 | 2 | 0 |
| 4 | 21 | `21 > 20` | above | 1 | 2 | 1 |

Очікуваний підсумок:

```text
below / inside / above = 1 / 2 / 1
```

Сума лічильників `1 + 2 + 1 = 4`, що дорівнює `n`.

## 5. Перевірки

| Тест | Ввід | Очікуваний результат |
|---|---|---|
| Граничні значення | `4 -11 -10 20 21` | `1 / 2 / 1` |
| Нижня межа | `1 -10` | `0 / 1 / 0` |
| Верхня межа | `1 20` | `0 / 1 / 0` |
| Нульова кількість | `0` | `Error:`, код 1 |
| Температура поза діапазоном | `1 101` | `Error:`, код 1 |
| Літери замість числа | `1 abc` | `Error:`, код 1 |
| EOF замість температури | `1` і кінець вводу | `Error:`, код 1 |
| Кількість більша за максимум | `31` | `Error:`, код 1 |

Для помилкового вводу підсумкові лічильники не друкуються. Програма завершується з кодом 1. Результат виводиться лише після успішного зчитування всіх `n` температур.
