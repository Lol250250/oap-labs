## Завдання 1. Обчислення характеристик трикутника

### Постановка
За трьома сторонами трикутника `a`, `b`, `c` обчислити півпериметр, площу за формулою Герона, радіуси вписаного й описаного кіл та висоту до сторони `a`.

### Формули
- `p = (a + b + c) / 2`
- `S = sqrt(p * (p - a) * (p - b) * (p - c))`
- `r = S / p`
- `R = a * b * c / (4 * S)`
- `h = 2 * S / a`

### Таблиця тестів

| Тип тесту | Вхідні дані `a b c` | Очікуваний результат |
|---|---|---|
| Контрольний | `3 4 5` | `p=6.00`, `S=6.00`, `r=1.00`, `R=2.50`, `h=4.00` |
| Межовий (рівносторонній) | `1 1 1` | `p=1.50`, `S=0.43`, `r=0.29`, `R=0.58`, `h=0.87` |

Програма розрахована на коректні додатні сторони трикутника, які утворюють невироджений трикутник.

## Завдання 2. Обчислення виразу (варіант 14)

### Постановка
Обчислити значення виразу:

`s = e^x * (x - y)^2 / (1 + z^2)`

### Обмеження на вхідні дані
Для дійсних `x`, `y`, `z` знаменник `1 + z²` завжди додатний, тому він ніколи не дорівнює нулю. Обмежень на знак `x`, `y` і `z` формула не встановлює. Для звичайних навчальних значень слід уникати надто великих `x`, за яких `exp(x)` може переповнити діапазон типу `double`.

### Псевдокод
1. Зчитати `x`, `y`, `z`.
2. Обчислити `difference = x - y`.
3. Обчислити `numerator = exp(x) * difference * difference`.
4. Обчислити `denominator = 1 + z * z`.
5. Обчислити `s = numerator / denominator`.
6. Вивести `x`, `y`, `z` і `s` з чотирма знаками після коми.

### Таблиця тестів

| Тип тесту | Вхідні дані `x y z` | Очікуваний результат |
|---|---|---|
| Контрольний | `0.5 -1.5 2` | `s = 1.3190` |
| Межовий | `1 1 0` | `s = 0.0000` |

## Завдання 3. Перерахунок гривень у валюту (додаткове)

### Постановка
За сумою у гривнях і курсами USD та EUR обчислити еквівалент суми в доларах США та євро.

### Формули
- `USD = UAH / usdRate`
- `EUR = UAH / eurRate`

### Таблиця тестів

| Тип тесту | Вхідні дані `UAH USD-rate EUR-rate` | Очікуваний результат |
|---|---|---|
| Контрольний | `10000 41.25 44.80` | `242.42 USD`, `223.21 EUR` |
| Межовий | `0 41.25 44.80` | `0.00 USD`, `0.00 EUR` |

Курси валют мають бути додатними.
