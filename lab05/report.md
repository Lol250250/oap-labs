## 1. Мета роботи

Навчитися обчислювати значення функції для заданого набору аргументів, використовувати цикл `for`, константи та перевірку області визначення перед обчисленням.

## 2. Варіант і формула

Для варіанта 14 задано функцію:

\[
y(x)=\frac{1}{x^2-1}.
\]

Область визначення: усі дійсні \(x\), крім \(x=-1\) та \(x=1\), оскільки знаменник не повинен дорівнювати нулю.

Параметри табулювання задані константами:
- \(a=-2\) — початкове значення аргументу;
- \(b=2\) — кінцеве значення аргументу;
- \(h=0.5\) — крок;
- \(i=0,\ldots,8\) — індекс рядка таблиці.

Аргумент обчислюється за формулою \(x=a+i\cdot h\). Значення \(b\) використовується як правий кінець інтервалу; за заданими параметрами останній аргумент дорівнює \(2\).

## 3. Псевдокод

```text
Початок
    Задати константи a = -2, b = 2, h = 0.5
    Для i від 0 до 8:
        x = a + i * h
        denominator = x * x - 1
        Якщо denominator дорівнює 0:
            вивести i, x, "undefined"
        Інакше:
            y = 1 / denominator
            вивести i, x, y
Кінець
```

## 4. Трасування

**Допустимий аргумент, x = 0:**

- Знаменник: \(0^2-1=-1\).
- Знаменник не дорівнює нулю.
- \(y=1/(-1)=-1\).
- Результат: `-1.0000`.

**Недопустимий аргумент, x = 1:**

- Знаменник: \(1^2-1=0\).
- Ділення не виконується.
- Результат: `undefined`.

Так само `undefined` отримуємо для \(x=-1\).

## 5. Таблиця значень

| i | x | y |
|---:|---:|---:|
| 0 | -2.0000 | 0.3333 |
| 1 | -1.5000 | 0.8000 |
| 2 | -1.0000 | undefined |
| 3 | -0.5000 | -1.3333 |
| 4 | 0.0000 | -1.0000 |
| 5 | 0.5000 | -1.3333 |
| 6 | 1.0000 | undefined |
| 7 | 1.5000 | 0.8000 |
| 8 | 2.0000 | 0.3333 |

## 6. Перевірки

- Кількість рядків таблиці: 9 — відповідає вимозі.
- Перший аргумент: \(x=-2\) — правильно.
- Останній аргумент: \(x=2\) — правильно.
- Крок: \(0.5\) — правильно.
- Для \(x=-2\): \(y=1/(4-1)=1/3\approx0.3333\).
- Для \(x=0\): \(y=1/(0-1)=-1.0000\).
- Для \(x=2\): \(y=1/(4-1)=1/3\approx0.3333\).
- Для \(x=-1\) та \(x=1\) знаменник дорівнює нулю, тому програма виводить `undefined`.
